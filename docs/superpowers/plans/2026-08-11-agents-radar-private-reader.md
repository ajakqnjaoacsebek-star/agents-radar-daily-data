# Agents Radar 私人阅读站 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建一个仅所有者可访问、自动读取 `ajakqnjaoacsebek-star/agents-radar-daily-data` 每日日报的 Sites 阅读站。

**Architecture:** GitHub Actions 在公开日报仓库内每天生成并提交 `digests/`、`manifest.json` 和 `highlights.json`。Sites 站点是无密钥静态客户端，每次加载或刷新时从该公开仓库 raw URL 拉取清单和 Markdown，因此新日报提交后无需重新发布网站。

**Tech Stack:** 原有 TypeScript/pnpm/GitHub Actions；Sites；原生 HTML、CSS、JavaScript；`marked` 与 `DOMPurify` CDN。

## Global Constraints

- 日报源仓库固定为 `ajakqnjaoacsebek-star/agents-radar-daily-data`，公开可读。
- Sites 访问策略仅允许站点所有者，不添加群组或外部访客。
- 不上传 `.env`、GitHub PAT、DeepSeek Key 或任何本机输出以外的敏感文件。
- 网站默认中文；同名 `-en.md` 存在时可切换英文。
- 本阶段只浏览既有日报和 highlights，不实现新的 5 条精选算法。

### Task 1: 建立可自动更新的日报源仓库

**Files:**
- Create remotely: `ajakqnjaoacsebek-star/agents-radar-daily-data`
- Modify: `.github/workflows/daily-digest.yml`
- Modify: `README.md`
- Exclude: `.env`, `node_modules/`, `agents-radar-source/`

**Consumes:** 当前 `agents-radar` 源码与已验证的 `daily-digest.yml`。

**Produces:** 一个公开 GitHub 仓库，其 `master` 分支每天提交 `digests/`、`manifest.json` 与 `feed.xml`。

- [ ] **Step 1: 创建公开仓库**

通过 GitHub 创建名为 `agents-radar-daily-data` 的公开仓库，description 填写 `Daily AI ecosystem digests generated by agents-radar.`，不要初始化 README、许可证或 `.gitignore`。

- [ ] **Step 2: 初始化并推送源码，不包含本机机密**

在项目根目录执行以下命令，并在提交前检查 `.env` 未被列入暂存区：

```powershell
git init
git add .
git diff --cached --name-only | Select-String -Pattern '(^|/)(\.env|node_modules)(/|$)'
git commit -m "chore: initialize daily radar source"
git branch -M master
git remote add origin https://github.com/ajakqnjaoacsebek-star/agents-radar-daily-data.git
git push -u origin master
```

`Select-String` 没有输出才继续提交；`.env` 与 `node_modules/` 已由现有 `.gitignore` 排除。

- [ ] **Step 3: 在 GitHub Actions 配置日报模型密钥**

在该仓库的 `Settings → Secrets and variables → Actions` 中创建名称精确为 `DEEPSEEK_API_KEY` 的 repository secret。原工作流已固定 `LLM_PROVIDER=deepseek`，无需创建其他 LLM secret。

- [ ] **Step 4: 手动触发一次 workflow 并验证远程数据**

在 Actions 中运行 `Daily Agents Radar`，完成后确认 raw URL 返回 JSON：

```text
https://raw.githubusercontent.com/ajakqnjaoacsebek-star/agents-radar-daily-data/master/manifest.json
```

验收标准：文件含 `dates` 数组；最新日期包含 `ai-hn` 与 `ai-trending`。

**Files:**

- Create: `sites/private-reader/data-source.test.js`

**Consumes:** `manifest.json`、`highlights.json`、`digests/YYYY-MM-DD/<report>.md`。

**Produces:** `loadManifest()`, `loadHighlights(date)`, `loadReport(date, reportId)` 与 `reportUrl(date, reportId)`。

- [ ] **Step 1: 写失败测试**

```js
import { strict as assert } from "node:assert";
import { reportUrl, selectLatestDate } from "./data-source.js";

assert.equal(
  reportUrl("2026-08-11", "ai-hn"),
  "https://raw.githubusercontent.com/ajakqnjaoacsebek-star/agents-radar-daily-data/master/digests/2026-08-11/ai-hn.md",
);
assert.equal(selectLatestDate({ dates: [{ date: "2026-08-10" }, { date: "2026-08-11" }] }), "2026-08-11");
```

- [ ] **Step 2: 运行测试并确认失败**

Run: `node sites/private-reader/data-source.test.js`

在 `data-source.js` 实现上述四个导出函数。`loadManifest`、`loadHighlights` 与 `loadReport` 必须在非 2xx 响应时抛出包含 HTTP 状态码的 Error。

- [ ] **Step 4: 运行测试并确认通过**

### Task 3: 实现每日阅读界面

**Files:**
- Create: `sites/private-reader/index.html`
- Create: `sites/private-reader/styles.css`
- Create: `sites/private-reader/app.js`

**Consumes:** Task 2 的 `loadManifest`, `loadHighlights`, `loadReport`。

**Produces:** 私人阅读站的首页、日期切换、报告切换和中英文切换。

- [ ] **Step 1: 建立结构化 DOM 与无障碍锚点**

`index.html` 必须包含 `#latest-date`、`#refresh-button`、`#date-list`、`#report-list`、`#highlights`、`#report-title`、`#report-content` 与 `#status-message`。加载 marked 与 DOMPurify CDN；报告渲染统一使用 `DOMPurify.sanitize(marked.parse(markdown))`。

- [ ] **Step 2: 实现状态与交互**

在 `app.js` 定义唯一状态对象：

```js
const state = { manifest: null, date: null, reportId: "ai-hn", language: "zh" };
```

启动时加载 manifest，选择最新日期和可用的首份中文报告；日期、类别、语言和刷新按钮均更新 state 后重新渲染。英文报告 ID 使用 `${reportId}-en`，仅在 manifest 报告数组包含该 ID 时显示切换控件。

- [ ] **Step 3: 实现失败和空状态**

`#status-message` 在 manifest 获取失败时显示 `无法读取日报清单，请检查网络后重试。`；当报告不存在时显示 `该数据源当天没有生成日报。`。失败状态不得保留为“最新”字样。

- [ ] **Step 4: 本地检查**

Run: `node sites/private-reader/data-source.test.js`

Expected: exit code 0；在浏览器中打开 `index.html` 后确认页面无密钥文本、HTML 控制台无 JavaScript error。
