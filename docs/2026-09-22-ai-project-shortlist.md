# 今天可以开始的 AI 项目清单

这份清单只保留本轮口味校准中你明确认可、愿意保留或表示有兴趣的方向，并按“今天开始是否划算”排序。

## 1. 项目点子关键假设验证器（最适合今天开始）

- 你会用到它的场景：脑海里冒出一个项目点子，但不想马上开工，也不想过几天忘掉。
- 它替你做什么：保存点子，找相似产品、真实讨论和反对证据，指出最可能让点子失败的假设。
- 你需要做什么：拿一个真实点子作为样本；亲自核对搜索证据；决定继续、缩小还是暂缓。
- 今天的最小目标：两小时内做出一张“点子证据卡”，不用先做完整网站。
- 难度：★★☆☆☆

## 2. 跨平台真实需求雷达（最值得长期做）

- 你会用到它的场景：想做有用或能赚钱的项目，但在学校遇不到足够多有需求的人。
- 它替你做什么：持续观察 GitHub Issues、Hacker News 等公开来源，把重复抱怨、求助和现有替代办法放在一起。
- 你需要做什么：先选两个公开来源；人工核对前十条；每周挑一个线索继续查证。
- 今天的最小目标：先收集一百条公开内容并验证“合并同类问题”是否靠谱，不接抖音登录态和复杂平台。
- 难度：★★★☆☆

## 3. 复现一个热门 AI 项目的核心能力

- 你会用到它的场景：看到网上热门项目觉得有意思，但只看介绍学不到实现方法，完整照抄又太大。
- 它替你做什么：帮助你找出项目最关键的一次输入、处理和输出，只复现这一小段。
- 你需要做什么：挑一个真正吸引你的热门项目；主动砍掉登录、支付和完整后台；做出可运行样品。
- 今天的最小目标：从 `ai-app-cloner` 的“截图变页面”中，只复现一个公开页面的可点击界面。
- 难度：★★★☆☆

## 4. 从真实需求到第一个可收费小产品（先验证，后开发）

- 你会用到它的场景：想让 AI 项目产生经济价值，但目前还没有明确的变现方向。
- 它替你做什么：把赚钱项目拆成需求证据、第一位用户、人工服务和自动化四步。
- 你需要做什么：先找真实问题和愿意反馈的人；人工完成一次；只自动化最贵或最容易出错的一步。
- 今天的最小目标：不写代码，只在两小时内找到一个问题、一种现有笨办法和一位可能愿意交流的人。
- 难度：★★★☆☆（难点主要不是代码）

## 5. 能听会说的实体感 AI 桌面伙伴（有整块时间再做）

- 你会用到它的场景：想做一个真正可见、可玩、能长期扩展的 AI 作品，而不只是网页小助手。
- 它替你做什么：把桌面角色、语音、记忆和硬件动作分层实现，前一层不好玩就不继续花钱。
- 你需要做什么：先跑通开源桌面伙伴；替换一个角色或动作；加入一次语音往返；最后才考虑买硬件。
- 第一次验证：先不买硬件，用半天确认自己是否真的喜欢常驻桌面伙伴。
- 难度：★★★★☆

## 暂时保留，但等场景出现

- 学习资料私人搜索：等开始备考或系统读书时再做。
- AI + 三维建模：只有模型要用于游戏、机器人、维修、售卖或其他真实后续用途时再做，不为摆件而做。
